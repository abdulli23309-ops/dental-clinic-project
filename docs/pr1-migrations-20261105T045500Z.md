## Migration 1: Backfill Service Providers Clinic ID

### Description
Populates `service_providers.clinic_id` from `team_members.clinic_id` for unscoped rows (`clinic_id IS NULL`).  
To preserve the business rule `DoctorServices(doctor, branch) ⊆ BranchServices(branch)` and prevent duplicate key violations, rows are updated ONLY when:
1. `team_members.clinic_id` is NOT NULL.
2. The branch explicitly offers the service in `clinic_services` (`is_active = TRUE`).
3. An explicit row for `(team_member_id, service_id, tm.clinic_id)` does not already exist.

### Pre-Flight Preview Query (Read-Only)
```sql
SELECT 
    COUNT(*) FILTER (WHERE sp.clinic_id IS NULL) AS total_unscoped_null,
    COUNT(*) FILTER (WHERE sp.clinic_id IS NULL AND tm.clinic_id IS NOT NULL AND cs.id IS NOT NULL AND NOT EXISTS (
        SELECT 1 FROM service_providers existing 
        WHERE existing.team_member_id = sp.team_member_id 
          AND existing.service_id = sp.service_id 
          AND existing.clinic_id = tm.clinic_id
    )) AS would_update_count,
    COUNT(*) FILTER (WHERE sp.clinic_id IS NULL AND tm.clinic_id IS NOT NULL AND cs.id IS NULL) AS skipped_not_offered_by_branch,
    COUNT(*) FILTER (WHERE sp.clinic_id IS NULL AND tm.clinic_id IS NOT NULL AND EXISTS (
        SELECT 1 FROM service_providers existing 
        WHERE existing.team_member_id = sp.team_member_id 
          AND existing.service_id = sp.service_id 
          AND existing.clinic_id = tm.clinic_id
    )) AS skipped_already_scoped_collision
FROM service_providers sp
JOIN team_members tm ON sp.team_member_id = tm.id
LEFT JOIN clinic_services cs ON cs.clinic_id = tm.clinic_id AND cs.service_id = sp.service_id AND cs.is_active = TRUE;
```

### Pre-Flight Preview Query (Read-Only)
```sql

SELECT tc.table_name, kcu.column_name
FROM information_schema.table_constraints tc
JOIN information_schema.key_column_usage kcu
  ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage ccu
  ON ccu.constraint_name = tc.constraint_name
WHERE ccu.table_name = 'service_providers'
  AND tc.constraint_type = 'FOREIGN KEY'
  AND tc.table_name != 'service_providers';

-- 2. Preview duplicate groups and proposed rows to discard:
WITH ranked AS (
    SELECT id, team_member_id, service_id, clinic_id, created_at,
           ROW_NUMBER() OVER (
               PARTITION BY team_member_id, service_id, clinic_id
               ORDER BY created_at ASC, id ASC
           ) as rn
    FROM service_providers
    WHERE clinic_id IS NOT NULL
)
SELECT * FROM ranked WHERE rn > 1;
```
